JAX implementation of BRACE, differential privacy for dense associative memory with LSR energy (arXiv 2610.11218). The released procedure is Algorithm 1, selected BRACE retrieval. Install with `pip install -e .`. Run the section 6.1 demo with `brace-lsr-demo`. Test with `JAX_PLATFORMS=cpu python -m pytest -q`.

What does not match the paper: the PDF typesetting of ρ collapses to ε^2 because the square roots cancel, so ρ is the positive root of ε = ρ + 2 sqrt(ρ log(1/δ)), namely (sqrt(log(1/δ) + ε) - sqrt(log(1/δ)))^2. Smooth sensitivity uses the closed-form envelope S = max(L0, 2r exp(-γ)) with L0 = 2r / max(1, |J|) when the correction indicator is off and L0 = 2r otherwise, then Δ = max(2r/n, S), instead of CorrectedCountSearch. γ_t is the paper's upper bound in equation (8), not a smaller unspecified value. Section 6.1 omits mixture weights, variances, and κ; the demo uses weights 0.4, 0.4, 0.2, mode standard deviation 0.15, center standard deviation 0.45, a central component at the origin, κ = 0.01, and seed 0, with the paper's query q = (0.2, 0.2). There is no MNIST or PCA experiment and no full-trajectory CLT.
